# Coastal Ledger Tax & Business Services

Bilingual demonstration website for a fictional tax, accounting and business services firm in Santa Barbara, California.

## Stack

- Next.js App Router
- TypeScript
- React
- CSS
- `next/image`

## Local development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```

## Languages

- English: `/`
- Español: `/es`

The language selector preserves the equivalent page across all principal routes and service pages.

## Demonstration notice

Coastal Ledger is a fictional business. Contact and booking interfaces remain clearly marked as demonstrations until a later GoHighLevel integration phase.
